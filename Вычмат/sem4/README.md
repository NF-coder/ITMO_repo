## О курсе
Небольшой курс, рассматривающий базовые вычислительные методы для решения СЛАУ, нелинейных уравнений и их систем, численного интегрирования, аппроксимации и интерполяции

## Рубежки
Представляют из себя пару, на которой вы будете под наблюдением кучи камер решать практические задачи. Пул типов задач известен вышлют заранее - просто соберите всю инфу со слайдов и скормите её нейронке чтобы составить задачи \
Списывать - дело гиблое, мониторят довольно хорошо
